# Yuki-QQbot 2.1.0

2.1.0 引入统一 Tool Kernel 和通用 MCP Client。Core、Admin、Automation、Plugin、MCP 使用同一
动态 Planner scope、工具目录、Binding、并发协调与结果预算；支持 stdio 和 Streamable HTTP，
并以 Alembic `0019` 非破坏性新增缓存、Artifact 和无正文调用指标表。

默认 `MCP_ENABLED=false`，升级后原有行为不变。启用前阅读 `docs/mcp/configuration.md`，复制
`.mcp.json.example`，并通过环境变量提供 Secret。本版本没有新增 MCP 专属审批流程。
